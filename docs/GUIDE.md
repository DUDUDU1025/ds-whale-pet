# 使用说明

从零开始，照着做完就行。不需要懂编程。

> 这份是**新手向导**。想看完整的功能参考（好感度公式、说话规则、配置项）去
> [MANUAL.md](MANUAL.md)。想知道怎么实现的去 MANUAL 的第二部分。

---

## 第 0 步：确认你的系统

**必须是 Windows。**

右键「此电脑」→「属性」，看「系统类型」是不是 `64 位操作系统`。

Mac 和 Linux **跑不了**——这个程序用了 Windows 专属的透明窗口、全屏检测和鼠标轮询。

---

## 第 1 步：装 Python

如果电脑里已经有 Python 3.8 或更高，跳到第 2 步。

### 怎么知道有没有

按 `Win + R`，输入 `cmd` 回车，在黑框里敲：

```
python --version
```

- 显示 `Python 3.x.x` → **有了**，跳到第 2 步
- 提示「不是内部或外部命令」→ **需要装**

### 怎么装

1. 打开 <https://www.python.org/downloads/>
2. 点那个大大的黄色按钮 **Download Python 3.x.x**
3. 运行下载的安装包
4. **⚠️ 最关键的一步**：安装界面最下面有个复选框

   ```
   ☑ Add python.exe to PATH
   ```

   **一定要勾上。** 不勾的话，后面每一步都会报「不是内部或外部命令」，
   而且很难排查是这个原因。

5. 点 **Install Now**，等它装完
6. **关掉所有黑窗口**（cmd），重新开一个再验证：

   ```
   python --version
   ```

   这次应该能看到版本号了。

---

## 第 2 步：把项目拿到本地

### 方式 A：下载压缩包（不用装 git，推荐新手）

1. 打开 <https://github.com/DUDUDU1025/ds-whale-pet>
2. 点绿色的 **Code** 按钮 → **Download ZIP**
3. 下载完解压到一个你找得到的地方，比如 `D:\ds-whale-pet`

### 方式 B：用 git（如果你已经装了 git）

```bash
git clone https://github.com/DUDUDU1025/ds-whale-pet.git
```

---

## 第 3 步：装唯一的一个依赖

**先进入项目文件夹**——这一步很多人漏掉，导致后面找不到文件。

在文件资源管理器里打开项目文件夹（能看到 `README.md`、`src`、`docs` 的那个），
然后**在地址栏里直接输入 `cmd` 回车**——会弹出一个黑窗口，路径已经是这个文件夹了。

敲：

```
pip install pillow
```

看到 `Successfully installed pillow-x.x.x` 就成了。

> 如果报 `pip 不是内部或外部命令`：说明第 1 步的 PATH 没勾上。
> 回到第 1 步重新装一遍，或者用 `python -m pip install pillow`。

---

## 第 4 步：启动

还是刚才那个黑窗口，敲：

```
python src\whale_pet.py
```

**屏幕右下角会冒出一只小鲸鱼。**

如果它出来了，你可以把这个黑窗口关掉了——不影响它运行。

### 想先看它长什么样、但不开窗口

```
python src\whale_pet.py --preview
```

会在 `assets\preview.png` 生成一张图，五格分别是：待机 / 看鼠标 / 眨眼 / 开心 / 打瞌睡。

---

## 第 5 步：怎么玩

| 你做什么 | 它怎么反应 |
|---|---|
| 什么都不做 | 呼吸、甩尾巴、偶尔喷水、眨眼 |
| 鼠标靠近 | 眼睛跟着你转，腮红变深（害羞） |
| **左键点一下** | 蹦起来，冒爱心 |
| **双击** | 跳更高，冒一串爱心 |
| **按住拖动** | 跟着走，身体朝移动方向歪 |
| **右键** | 打开菜单 |
| 放着不管 30 秒 | 打瞌睡，闭眼、飘 zZ、说梦话 |

### 右键菜单里有

- **摸摸头** —— 好感度 +1，蹦两下
- **喂一条小鱼** —— 见下面
- **换个配色** —— 深海 / 月光 / 薄荷 / 棠梨 / 夜航 五套
- **哄它睡觉** —— 立刻打瞌睡
- **再见了** —— 退出

### 喂鱼

1. 右键 → **喂一条小鱼**
2. 会出现一条小鱼挂在鼠标右下角，跟着你跑
3. 鲸鱼的眼睛会一直盯着那条鱼
4. **左键点一下** → 鱼被放下（鱼就在光标上，点哪儿都一样）
5. 鲸鱼游过去，吃掉，冒爱心
6. 吃完就待在那儿（想让它回角落，拖着走）

喂的过程中想取消：**右键**一下，鱼就收回去了。

### 它会记住

关掉再打开，它还记得：

- 认识你多少天
- 被摸过几次
- 被喂过几条

数据存在 `data\.whale_state.json`。**删掉这个文件 = 失忆，从认识第一天开始。**

---

## 第 6 步（可选）：让它开机自启

1. 按 `Win + R`，输入 `shell:startup` 回车，会打开「启动」文件夹
2. 在「启动」文件夹里右键 → **新建** → **快捷方式**
3. 在「请键入对象的位置」里填（注意替换成你的实际路径，`pythonw.exe` 前面的路径也要对）：

   ```
   C:\Users\你的用户名\AppData\Local\Programs\Python\Python312\pythonw.exe "D:\ds-whale-pet\src\whale_pet.py"
   ```

   > 用 `pythonw.exe` 而不是 `python.exe`，这样开机不会弹黑窗口。

4. 下一步 → 起名叫「小鲸鱼」→ 完成

**不用担心开两次**：程序内置了单实例锁，开机自启和手动启动撞一起也只会有一只。

## 常见问题

### 双击没反应 / 一闪就没了

说明出错了，但 `pythonw` 不显示错误。改用 `python` 跑一遍看报错：

```
python src\whale_pet.py
```

### `ModuleNotFoundError: No module named 'PIL'`

依赖没装上。回第 3 步，确认是在**项目文件夹里**执行的 `pip install pillow`。

### `python 不是内部或外部命令`

第 1 步的 **Add python.exe to PATH** 没勾。重新运行 Python 安装包，
选 **Modify**，把 PATH 相关的选项勾上。

### 它不见了

- 先看屏幕**右下角**（可能在任务栏后面）。
- 如果拖到屏幕边缘外了，程序会自己把它拽回来，等一两秒。
- 实在找不到：打开 `data\.whale_state.json`，把 `"pos": [x, y]` 那两行删掉，重启。

### 太费电 / 风扇响

程序空闲 15 秒会自动降到 12fps（单核约 8%）。如果还是嫌高，打开
`src\whale_pet.py`，最上面找到：

```python
TARGET_FRAME_MS = 24   # 改成 33，就是 30fps
S = 2                  # 改成 1，省一半 CPU，代价是边缘有锯齿
```

### 打游戏时它挡住画面

全屏游戏（盖住任务栏那种）会自动躲起来，切回来再出现。
如果某些游戏是全屏但没盖住任务栏，可能判断不出来——这时右键选「再见了」，
玩完再启动。

### 中文显示成方块

气泡和 zZ 依赖 Windows 自带的**微软雅黑**字体。精简版系统可能把它删了，
装回微软雅黑即可。

---

## 卸载

1. 右键小鲸鱼 → **再见了**
2. 删掉整个项目文件夹
3. 如果做过开机自启，去 `shell:startup` 里删掉那个快捷方式

没有注册表残留，没有系统目录写入。
