## 第一部分 · 使用

### 启动

```bash
pip install pillow
python whale_pet.py
```

Windows 上也可以直接双击文件夹里的 `启动小鲸鱼.lnk`。

| 命令 | 作用 |
|---|---|
| `python whale_pet.py` | 启动桌宠 |
| `python whale_pet.py --preview` | 只渲染一张状态图，不开窗口（用来检查画得对不对） |

程序自带单实例互斥体：重复启动不会出现第二只，后来的会安静退出。

### 交互

| 你做什么 | 它怎么反应 |
|---|---|
| 什么都不做 | 呼吸浮动、甩尾巴、偶尔头顶喷一小股水、随机眨眼 |
| 待机久了 | 会自己找点事做：扭头看看、甩两下尾巴、抖一抖、打个哈欠、伸个懒腰 |
| 鼠标靠近 | 眼睛跟着光标转，腮红变明显（害羞） |
| 点一下 | 蹦起来，冒一颗爱心 |
| 双击 | 跳更高，冒一串爱心 |
| 按住拖动 | 跟着走，朝拖动方向歪过去，尾巴甩得更凶 |
| **快速拖动后松手（甩）** | 飞出去，撞到屏幕边缘会弹回来，慢慢减速停下 |
| 30 秒没互动 | 打瞌睡：闭眼、飘 zZ、开始说梦话 |
| 动一下鼠标 | 立刻醒 |
| 右键 | 打开菜单 |

### 右键菜单

| 菜单项 | 作用 |
|---|---|
| 认识 N 天 · 摸头 N 次 · 关系 | 只读，显示当前关系状态 |
| 摸摸头 | 好感度 +1，冒 3 颗爱心，蹦一下 |
| 喂一条小鱼 | 进入喂鱼流程，见下 |
| 换个配色 | 深海 / 月光 / 薄荷 / 棠梨 / 夜航，循环切换 |
| 哄它睡觉 | 立刻进入瞌睡状态（窗口不会消失） |
| 再见了 | 退出 |

### 喂鱼

1. 右键 → **喂一条小鱼**
2. 一条小鱼出现在光标右下方，跟着你走，尾巴一甩一甩
3. 按住左键时它会「受惊」，尾巴甩得飞快
4. 全程鲸鱼的眼睛都盯着它
5. **左键点任意位置** → 鱼被放下
6. 鲸鱼朝那儿游过去，吃掉
7. 吃完就地待着，不回家（想让它回角落就拖着走）

喂鱼过程中：

- **右键** → 把鱼收回去，取消这次喂食
- 喂到嘴里才算数：`feeds` 计数 +1，好感度 +2

### 记忆与好感度

数据存在脚本旁边的 `.whale_state.json`：

```json
{
  "first_met": 1792918209.6,
  "pets": 12,
  "feeds": 3,
  "total_seconds": 455.0,
  "last_seen": 1792918746.5
}
```

| 字段 | 含义 |
|---|---|
| `first_met` | 第一次见面（Unix 时间戳），用来算「认识几天」 |
| `pets` | 被摸头的累计次数 |
| `feeds` | 被喂鱼的累计条数 |
| `total_seconds` | 累计陪你多久（每次存档时累加） |
| `last_seen` | 上次活跃时间 |

**好感度** = 摸头次数 + 喂食次数 × 2 + 认识天数 × 3

| 好感度 | 关系 | 表现 |
|---|---|---|
| 0–9 | 刚认识 | 说话客气，偶尔「……你好呀」 |
| 10–29 | 熟悉 | 正常聊天 |
| 30–59 | 亲近 | 话变多，「今天也想多看你一会儿」 |
| 60+ | 黏人 | 爱心最多，说话最频繁 |

好感度不会掉，只会慢慢涨。

### 它什么时候说话

气泡随机出现，间隔随关系变亲而缩短。另外有几种**固定触发**：

| 触发条件 | 说什么 |
|---|---|
| 距上次吃鱼满 3 分钟 | 「主人 饿饿 想吃鱼鱼」 |
| 连吃 3 条鱼 | 「吃的好饱 最喜欢主人了」 |
| 睡着时（梦话，另一套词池） | 「嘿嘿 把你的鱼鱼吃光光」「啊 好多小鱼鱼啊」… |

清醒和睡着的词池是分开的，睡着时不会说「记得喝水」这类正常话。

#### 它会看时间和你的作息

有四成概率不说通用的话，而是说**「此时此刻」才成立**的话：

| 时段 | 会说 |
|---|---|
| 0–5 点 | 「这个点了还不睡？」「……你也没睡啊」 |
| 5–9 点 | 「早呀」「早饭吃了吗」 |
| 9–12 点 | 「上午好」「今天想干点什么」 |
| 12–14 点 | 「吃饭了吗」「别光顾着敲键盘」 |
| 14–18 点 | 「喝口水吧」「眼睛离屏幕远一点」 |
| 18–22 点 | 「今天过得怎么样」「天黑了」 |
| 22–24 点 | 「差不多该休息了」「睡前别刷手机」 |

而且会算**这次启动后它陪了你多久**：

| 连续陪伴 | 额外说的 |
|---|---|
| 满 1 小时 | 「忙了挺久了吧」 |
| 满 2 小时 | 「坐了两个多小时了，起来走走」 |
| 满 4 小时 | 「四个小时了……真的该歇了」 |

这个计时不跨进程——重启就重新算，`total_seconds` 那个才是累计值。

#### 它认得你在用哪个 AI

它每 2 秒看一眼前台窗口的标题，认出你当前在用哪个 AI，**只在切换的时候反应一次**：

| 你切到 | 它会说 | 动作 |
|---|---|---|
| DeepSeek / DeepSeek Harness | 「DeepSeek！是我家！」「你在用 DeepSeek 呀，我就知道」 | 冒爱心、蹦一下 |
| ChatGPT | 「GPT 姐姐也很聪明…但我还是吃醋了」 | 扭头、斜眼 |
| Claude | 「Claude 姐姐写得好看…但我还是吃醋了」 | 扭头、斜眼 |
| 豆包 | 「豆包啊…名字听着就好吃」 | 扭头 |
| Grok | 「Grok 那个嘴毒的…你别学它」 | 扭头 |
| Gemini / Kimi / 通义 / Copilot / 文心一言 | 各有对应的一句 | 扭头 |
| 不认识的 AI | 「这个我不认识…它也是 AI 吗」 | 扭头 |

看自己家会**得意**，看别家会**吃醋**——毕竟它是 DeepSeek 家的鲸鱼。

**保护措施**：

- **只在切换时说**，你一直开着一个窗口它不会反复念
- **20 秒冷却**，同一段时间内不重复
- **睡觉、拖动、喂鱼时完全不检测**，不打断你

**它看的是什么**：前台窗口的标题栏文字（`GetForegroundWindow` + `GetWindowText`）。
**不读文件、不截屏、不联网。**

如果你开着两个 AI 窗口，它认的是**当前在最前面那个**。

### 全屏时会发生什么

前台如果是**盖满整个显示器（连任务栏都盖掉）**的程序，它会自动躲起来；切回来再冒出来，位置不变。

普通最大化的窗口不算全屏，它还会照常待着。

### 开机自启（Windows）

把 `pythonw.exe whale_pet.py` 的快捷方式放进：

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup
```

或者用任务管理器 → 启动应用 管理。

### 改配置

打开 `src/whale_pet.py`，顶部的常量就是配置：

| 常量 | 作用 | 默认 |
|---|---|---|
| `WIN` | 窗口边长（像素） | `180` |
| `S` | 超采样倍率，影响清晰度和 CPU | `2` |
| `BG_HEX` | 透明键用的幕布色 | `#0a081e` |
| `SKINS` | 配色方案列表 | 5 套 |
| `FISH_W` / `FISH_H` | 小鱼窗口尺寸 | `46` / `34` |
| `TARGET_FRAME_MS` | 有交互时的帧长，越小越顺越费电 | `24`（约 42fps） |
| `IDLE_FRAME_MS` | 空闲时的帧长 | `80`（约 12fps） |
| `IDLE_AFTER_SEC` | 多久没交互算空闲 | `15` 秒 |
| `THROW_MIN_SPEED` | 甩出去的最低速度（px/s），低于这个原地停下 | `320` |
| `BOUNCE` | 撞到屏幕边缘后保留的速度比例 | `0.55` |
| `FLY_FRICTION` | 飞行阻尼，越大停得越快 | `3.2` |
| `FLY_STOP_SPEED` | 慢到这个速度就判定落地 | `40` |

改完重启生效。

#### 调甩抛手感

觉得甩不动就调小 `THROW_MIN_SPEED`（比如 200）；觉得飞太远就调大 `FLY_FRICTION`（比如 5.0）；
嫌撞边弹得太厉害就把 `BOUNCE` 降到 0.35。

#### 关于 CPU

它会**自己看有没有人理**：连续 15 秒没交互就把帧率降到 12fps，
鼠标一动、被点、开始喂鱼立刻回到 42fps。

实测单核占用：

| 状态 | CPU |
|---|---|
| 空闲（12fps） | 约 8% |
| 有交互（42fps） | 约 24–30% |

嫌费电就把 `TARGET_FRAME_MS` 调到 `33`（30fps），或者把 `S` 改成 `1` 关掉超采样
（约 4ms/帧，代价是边缘有锯齿）。

#### 它会记住位置

关掉前待在哪儿，下次启动就回到哪儿。第一次运行才摆到右下角。

想让它回默认位置：删掉 `data/.whale_state.json` 里的 `pos` 字段，或者整个文件
（后者会把记忆一起清空）。

### 退出

右键 → 再见了，或者直接结束进程。

按 `Esc` 也会退出（窗口有焦点时）。

## 第二部分 · 实现

写给想改代码或者好奇怎么实现的人。这部分只讲「怎么做的」和「踩过什么坑」，
使用上的问题看上面第一部分就行。

### 代码结构

`whale_pet.py` 单文件，约 1200 行，按职责分段：

| 段落 | 内容 |
|---|---|
| 常量区 | 窗口尺寸、配色、幕布色、`WHALE_PATH`（logo 的 SVG 路径） |
| `parse_path()` | 极简 SVG 路径解析器（M/L/H/V/C/S/Z），贝塞尔采样成折线 |
| `render_frame()` | 画一帧：变形 → 上色 → 抠图，返回 PIL Image |
| `render_fish()` | 画那条跟着鼠标的小鱼 |
| `WhalePet` | 窗口、事件、动画状态机、喂鱼流程 |
| `preview()` | 渲染状态图，不开窗口 |

#### 渲染管线的顺序

```
原始折线点
  ↓ 尾巴摆动（按 x 坐标加权，绕尾巴根部旋转）
  ↓ 呼吸缩放 + 整体旋转 + 弹跳位移
  ↓ 归一化到画布坐标
  ↓ 分层生成 mask（身体 = 外轮廓 - 肚皮 - 眼白）
  ↓ 各层上色（渐变身体、高光、肚皮、腮红、眼睛）
  ↓ 缩回目标尺寸（LANCZOS，抗锯齿）
  ↓ 抠幕布色
  ↓ 交给 tkinter 显示
```

每一帧 6–7ms，30fps 预算 33ms，余量很大。

#### 为什么尾巴是「变形」而不是「整体平移」

鲸鱼轮廓是一整条闭合路径（889 个点）。直接平移整条路径的话，尾巴摆动时身体也会跟着晃。

做法是：对每个点按它的 x 坐标算一个权重（`smoothstep`，从尾巴根部 0 过渡到尖端 1），
然后用这个权重去缩放旋转角度，绕着尾巴根部旋转。这样根部几乎不动、尖端摆得最厉害，
看起来像有筋骨。

### 坑一：透明窗口的抠图不能用灰度差

`tkinter` 的 `-transparentcolor` 只能抠**一种精确颜色**，没有 alpha 通道可用。

所以流程是：铺一层幕布色 `#0a081e` 画整张图 → 画完之后把所有「像幕布」的像素压回幕布色 →
交给窗口去抠。

问题在于「像」怎么定义。

最初用**灰度差**：

```python
diff = ImageChops.difference(img, Image.new("RGB", img.size, BG))
mask = diff.convert("L").point(lambda v: 255 if v < 40 else 0)
```

结果**眼睛变透明了**。因为瞳孔原本用的是描边色 `#101838`，和幕布 `#0a081e` 的灰度差只有 **14**，
远小于阈值 40，于是被当成背景一起抠掉，眼睛那块直接透出桌面。

改成**逐通道**判断（三个通道都接近才算背景）：

```python
r, g, b = img.split()
m = None
for ch, target in ((r, BG[0]), (g, BG[1]), (b, BG[2])):
    one = ch.point(lambda v, t=target: 255 if abs(v - t) < 12 else 0)
    m = one if m is None else ImageChops.multiply(m, one)
img = Image.composite(Image.new("RGB", img.size, BG), img, m)
```

同时把瞳孔改成**纯黑**，和幕布的蓝通道拉开距离。

### 坑二：DPI 缩放让窗口飞到屏幕外

150% 缩放的屏幕上，`winfo_screenwidth()` 报的是物理像素，但
`geometry(f"+{x}+{y}")` 的绝对坐标不一定按同一套解释。用绝对定位时窗口能被放到屏幕外，
表现就是「进程在跑，但什么都看不到」。

最后改用**相对定位**：

```python
self.root.geometry(f"{WIN}x{WIN}-60-120")   # 距右 60、距下 120
```

再用 `GetSystemMetrics` + `SetWindowPos` 精确定位兜底。

### 坑三：`SetWindowPos` 对 Tk 的 Toplevel 无效

喂鱼时那条小鱼是个独立的 `Toplevel` 窗口。一开始用 `SetWindowPos` 移动它：

```python
hwnd = u.GetAncestor(self.fish_win.winfo_id(), 2)
u.SetWindowPos(hwnd, -1, x, y, FISH_W, FISH_H, 0x0010)
```

**返回 0，`GetLastError` 是 1400 `ERROR_INVALID_WINDOW_HANDLE`**，而且**静默失败**——
没有异常，鱼窗口就一直卡在 `(0,0)`，看起来像「鱼根本没跟手」。

Tk 自己的窗口只能用 `geometry()` 移动：

```python
self.fish_win.geometry(f"{FISH_W}x{FISH_H}+{x}+{y}")
```

顺带确认了：这台机器上 Tk 坐标和 `GetCursorPos` 完全一致，所以直接混用没有问题。

### 坑四：轮询鼠标要记住「按下」

放鱼靠 `GetAsyncKeyState(VK_LBUTTON)` 轮询。最初只在**松开**时判断：

```python
if not pressed and self._lbtn_down:
    self._drop_fish()
```

但 `_lbtn_down` 从来没被设成 `True` 过，所以只在「点在鲸鱼窗口上」（走 `on_press` 事件）
的时候才生效——表现就是**鱼只能放在鲸鱼旁边**。

后来改成先记按下：

```python
if pressed and not self._lbtn_down:
    self._lbtn_down = True
elif not pressed and self._lbtn_down:
    self._lbtn_down = False
    self._drop_fish()
```

再后来发现「按下→松开」这个完整周期也可能漏（按下和松开落在同一帧里），
干脆改成**按下即放**：

```python
if pressed and not self._lbtn_down:
    self._lbtn_down = True
    self._drop_fish()
```

### 坑五：一次异常会冻住整只鲸鱼

`tick` 里任何一步抛异常，后面的 `self.root.after(33, self.tick)` 就不会被执行，
动画**永久停止**——看起来像卡死，但实际上进程还活着，窗口也还在。

所以现在所有调度都放进 `finally`：

```python
def tick(self):
    try:
        self._tick_once()
    except Exception:
        traceback 写日志
    finally:
        try:
            self.root.after(33, self.tick)
        except tk.TclError:
            pass
```

配合 `pythonw` 没有控制台的特点，异常还会写进 `whale_pet_error.log`。

### 全屏检测

判断「前台窗口是不是盖满了整个显示器」用的是 `MonitorFromWindow` + `GetMonitorInfoW`：

```python
r = GetWindowRect(foreground)
m = GetMonitorInfoW(MonitorFromWindow(foreground)).rcMonitor
is_fullscreen = (r.left <= m.left and r.top <= m.top and
                 r.right >= m.right and r.bottom >= m.bottom)
```

关键点是**比对 `rcMonitor` 而不是 `rcWork`**。最大化窗口只盖住工作区（会把任务栏让出来），
用 `rcWork` 判断的话所有最大化窗口都会被误判成全屏。

同时排除 `Progman` / `WorkerW` / `Shell_TrayWnd` 这几个桌面窗口类。

### 小动作系统

呼吸和摆尾是「底色」，但只有底色会显得机械。所以上面还盖了一层 gesture 状态机：
闲下来 4~13 秒后挑一个动作执行，用 `sin(pi*p)` 做包络（起落都归零，不会突兀），
翻译成 `render_frame` 的两个额外标量：

| 动作 | squash | tail_extra | 效果 |
|---|---|---|---|
| `look_around` | 0 | 0 | 视线偏向一侧再回来 |
| `tail_flick` | 0 | 0~1.1 | 尾巴短促甩两下 |
| `shiver` | ±0.085 | 0 | 全身快速抖 |
| `yawn` | -0.07 | 0~0.2 | 闭眼、身体拉长、视线下垂 |
| `stretch` | -0.10 | 0~0.45 | 身体拉长、尾巴翘起 |

两个参数的含义：

- `squash` 纵向拉伸/压扁（负值拉长）
- `tail_extra` 尾巴额外摆幅，同时把摆动频率也往上推

鲸鱼没有画嘴——它的脸只有眼睛和腮红，跟 logo 一样干净。
打哈欠靠「闭眼 + 拉伸 + 视线下垂」表达。

另外呼吸频率不再是固定的 1.75Hz，而是 `1.7 + 0.22*sin(t*0.19)` 缓慢漂移，
避免「机械等周期」的观感。

### 性能

单帧渲染约 7ms（180px 窗口，2 倍超采样）。帧调度按实际耗时反推，不是死等：

```python
elapsed = (perf_counter() - t0) * 1000
delay = max(1, int(round(TARGET_FRAME_MS - elapsed)))
root.after(delay, tick)
```

`TARGET_FRAME_MS` 默认 `24`（约 42fps），实测稳定运行时单核占用约 **19%**。

嫌费电可以调：

| 改法 | 帧率 | 单核占用 |
|---|---|---|
| `TARGET_FRAME_MS = 33` | 30fps | 约 13% |
| `S = 1`（关掉超采样） | 不变 | 约 8%，但边缘有锯齿 |

### 边界保护

窗口拖动时会用虚拟屏幕边界（`SM_XVIRTUALSCREEN` 等四项）夹住，至少保留 55% 露在外面：

```python
minx, maxx = vx - w + keep, vx + vw - keep
```

`_ensure_visible` 每秒顺手检查一次：整扇窗都在屏幕外就拽回来。
这防的是「拖出去以后再也没法点右键」的死局。

### 状态文件损坏的处理

`load_state` 读失败时不再静默重置，而是：

1. 把坏文件改名成 `.whale_state.json.broken-<时间戳>` 保留下来
2. 往 `data/whale_pet_error.log` 记一笔
3. 才返回一份全新的状态

### 已经删掉的实现

- `feed()`：早期「点菜单直接加好感度」的版本，改成喂鱼流程后没有调用了
- `home_pos` / `_return_at`：吃完鱼游回原位的逻辑，用户要求改成「吃完就地待着」后删掉
- `boost`：渲染参数，写了但从没传过非零值（`squash` 后来被动作系统重新启用）

### 已知限制

- 只在 Windows 上测过：用了 `SetWindowRgn`、`-transparentcolor`、`GetAsyncKeyState`、`GetCursorPos`
- 梦话气泡依赖 Windows 自带的微软雅黑（找不到会退回默认字体，中文会变方块）
- 多显示器只处理主屏
- 全屏检测对「没盖住任务栏的无边框全屏」会漏判
